# Yugal Sunil Patil — Portfolio

A small static portfolio built with plain HTML, CSS, and JavaScript. Its layout is inspired by kien.app; the copy, project information, and screenshots are Yugal's.

## Run locally

From this folder, start a local server:

```bash
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in a browser.

## Before publishing

- Verify project descriptions, status, technologies, and your personal contribution.
- Confirm which social links and résumé you want public.
- Check the site at mobile width and keyboard-only navigation.
- `assets/nebulith-explorer.jpg` and `assets/nebulith-digital-twin.jpg` are screenshots copied from the NEBULITH project. Do not present them as screenshots of other projects.

Typography uses Unbounded for headings, Inter for body copy, Inter Tight for interface text, and JetBrains Mono for terminal elements, with system fallbacks if Google Fonts is unavailable. Desktop uses horizontal full-screen sections; narrow screens switch to vertical scrolling and a menu button.
